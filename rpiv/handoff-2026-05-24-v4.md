## 经验沉淀（跨会话价值）

1. **pygame.joystick.quit() + init() 不重新枚举设备 (SDL 行为)** —— 5/24 verify v1 失败后纠正, 必须用 pygame.event.get() + JOYDEVICEADDED/REMOVED. SDL 2.x 热插拔标准模式.
2. **DS4 不允许 host 主动 connect** —— `bluetoothctl connect <DS4>` 报 `br-connection-create-socket`, 必须 DS4 端按 PS 键发起广播. DS4 固件特性.
3. **vendor obs build 路径在 stub vs attached 时维度不同** —— stub 时 101 维, attached 时 108 维 (多 7 = commands 完整). 这是 ONNX 训练时假设 commands 总在 vs vendor 代码省略路径的不一致. 修 obs build 是核心.
4. **systemd restart loop 跟 vendor crash 配合** —— Restart=on-failure + RestartSec=5 让 vendor crash 自动 recover, 但 obs bug 这种 crash 一直 restart 一直 crash. 监控 journal 看是否进入 loop.
5. **Pi DVFS 自适应电压跟 throttle 联动** —— 高频满载 1.3125V, 降频后掉到 1.2V 区. 不要凭电压瞬时低判电池不足, 必须同时看 throttle bit 3 + 真实电池/电源链路.
6. **用户视角是 ground truth** —— 用户从后面看鸭子 (vendor coord 一致), 用户视觉 "右腿 stall" = vendor ID 10-14 范围. 我之前在 verify 数据基础上假设 outlier 是左腿, 跟用户视觉冲突时优先用户视觉.
