> 源: 优利德 UDP6730 系列使用说明书 REV 1 (2023.01.07), 软件 V1.03, 20 页全册精简。
> 适用: guagua 项目桌面调试鸭子 (Pi 3B+ 整机 + 14 ST3215 + 2 SG90), 标称 12V 直流。
> 文档定位: `docs/` 持久化资料, 全册原始 PDF 见 [`UDP6730系列使用手册REV.1.pdf`](UDP6730系列使用手册REV.1.pdf)。
> 接线方案: 见 [`udp6730-wiring-howto.html`](udp6730-wiring-howto.html) (4 步图解 + 方案 A 镀锡 / 方案 C 压接 VE6-12 端子). 工具采购见 [`wiring-toolset-shopping-list.md`](wiring-toolset-shopping-list.md).

## 0. 通电前 4 项硬约束 (顺序不能颠倒)

| 检查项 | 怎么验证 | 不通过的后果 |
|---|---|---|
| **后面板 AC SELECTOR 在 220V** | 看后面板红色拨片开关写的是 `220V` 还是 `110V` | 拨到 110V 接 220V 市电 → 保险丝烧 (出厂装 250V/5A 对应 220V; 110V 才需要 250V/8A) |
| **3 芯电源线地线接地** | 用市电插座 (国标 3 孔), 不要用 2 孔接线板 | 测量精度下降 + 触电隐患 (说明书"仪器接地"明文要求) |
| **OUTPUT 关 (没绿灯)** | 前面板 OUTPUT 按键灯灭 | 上电瞬间冲击负载 (鸭子未接尚可,接了鸭子非常危险) |
| **输出端口空载** | 红/黑香蕉孔什么都不接 | 同上,且空载是检验设备本身的标准方法 |

⚠️ **AC SELECTOR 是新机最容易忽视的死点**。开箱第一件事先转到后面板确认。

## 1. 前面板按键速查 (按使用频率排序)

| 按键 | 短按 | 长按 |
|---|---|---|
| **V** | 进入电压设定栏 | **设 OVP 过压保护值** ⭐ |
| **A** | 进入电流设定栏 | **设 OCP 过流保护值** ⭐ |
| **M1 / M2 / M3** | 调用对应存储组 (前提:MENU 已选过存储组号) | **保存当前 V/A 设定到该组** ⭐ |
| **OUTPUT** | 开/关输出 (灯亮=开) | — |
| **LOCK** | 锁键盘 (防误碰), 再短按解锁 | — |
| **MENU** | 进系统设置 (7 项) | — |
| **ESC** | 退出 / 返回上一级 | — |
| **ENTER** | 确认 | — |
| **← →** | 移光标到不同数位 | — |
| **旋钮编码器** | 调当前数位的数值 | 在 List/Delayer 界面: 切 Run/Stop |

**数值设定的通用三步**: 按 V (或 A) 进设定栏 → ← → 移到要改的数位 → 转旋钮调值 → 按 ENTER 确认。

## 2. 鸭子专用预设 (开机第一件事就配)

### 2.1 三档电流限流的设计意图

| 档位 | 设置 | 适用场景 |
|---|---|---|
| **M1** | 12V / **8A** | 静止 + 对话 + 表情演示 (起步保守, 出问题就是 OCP 跳, 不会烧舵机) |
| **M2** | 12V / **15A** | 局部动作演示 (头+1 条腿) |
| **M3** | 12V / **25A** | 走 walk policy / 全身激烈动作 (留 5A 余量到 30A 上限) |
| **OVP** (全档共用) | **14V** | 误调到 24V 时立即跳保护 (鸭子标称 12V, 14V 是 ST3215 6-14V 工作上限) |
| **OCP** (M3 档共用) | **28A** | 留 2A 余量到 30A 设备上限 |

> OVP/OCP 是**硬保护**, 一旦触发会强制关断 OUTPUT, 不损坏鸭子。比"凭眼力调电压"安全 10 倍。

### 2.2 配置流程 (照抄按键序列)

**① 设 M1 = 12V / 8A**:
```
按 V → ← → 移光标 → 旋钮调到 12.00 → ENTER
按 A → ← → 移光标 → 旋钮调到 08.00 → ENTER
长按 V (≥ 1 秒) → 进 OVP 设置栏 → 旋钮调到 14.00 → ENTER (右边出 √ 标志 = 激活)
长按 A (≥ 1 秒) → 进 OCP 设置栏 → 旋钮调到 28.00 → ENTER (同上)
长按 M1 (≥ 1 秒) → 看屏幕短暂提示 "保存成功" 即 OK
```

**② 设 M2 = 12V / 15A**:
```
按 A → 改成 15.00 → ENTER (V/OVP/OCP 都不动)
长按 M2 → 保存
```

**③ 设 M3 = 12V / 25A**:
```
按 A → 改成 25.00 → ENTER
长按 M3 → 保存
```

**调用时 (重要陷阱)**:
- 短按 M1/M2/M3 在主界面**不一定生效**, 必须先 MENU → 存储组 → 选定要调用的组号 (1/2/3 对应 M1/M2/M3) → 再按对应键, 这时该键长亮绿灯表示当前在用。
- 当前用哪组,看屏幕右上角 `MEM:00X` 标识。

## 3. MENU 系统设置 (7 项)

进 MENU 后, 左右键切项, 旋钮调值:

| 项 | 推荐值 (鸭子调试) | 说明 |
|---|---|---|
| 1. 蜂鸣器 | **关** | 按键不出声, 调试时不烦 |
| 2. 背光亮度 | 50-70 | 默认 50 够看 |
| 3. 存储组 | **1** | 配合 M1/M2/M3 调用 |
| 4. 输出状态 | **关闭** (默认) | 上电默认 OUTPUT 关; 选"保持"则上次状态保留 (鸭子调试**不要选保持**, 防开机瞬间冲鸭子) |
| 5. Language | 简体中文 / English | 看个人 |
| 6. 接口信息 | (只读) RS232: 9600/8/N/1 | 后续 SCPI 用 |
| 7. 关于本机 | (只读) 型号 + 软件版本 | 排障时贴给客服 |

## 4. 空载验机 (上电后第一件做的事, 不要接鸭子)

万用表准备好, 转到 **V⎓ (直流电压)** 档。

```
1. 后面板 AC SELECTOR 确认 220V → 接 3 芯电源线 → 后面板 POWER 拨到 I (开)
2. 屏幕亮起, MEM:001 默认在 M1 (上一步刚配的 12V/8A)
3. 调用 M1: MENU → 存储组 → 选 1 → ESC 退回主界面 → 短按 M1
4. **OUTPUT 仍保持关闭**, 输出端口空载 (红黑香蕉孔什么都不接)
5. 短按 OUTPUT → 灯亮绿色, 屏幕显示 "ON", 模式 "CV" (恒压)
6. 万用表红表笔扎红色香蕉孔, 黑表笔扎黑色 →
   读数应在 +11.97 V ~ +12.03 V 之间 (说明书设置精度 <0.1% + 30mV, 12V 时绝对误差 < 42 mV)
7. 短按 OUTPUT 关闭 → 测量结束
```

**验机通过的标志**:
- 屏幕显示 12.00 V / 8.00 A / 0.00 W (空载电流 0)
- 万用表读数 12.0 ± 0.05 V
- CV 灯亮绿色 (右下角 CV/CC 状态灯)
- 风扇转得平稳, 不咔咔异响

不通过的常见原因 (来自手册"问题排除"):
1. 电压/电流设定为 0 → 重新设
2. OUTPUT 灯没亮 → 再短按一次
3. OVP/OCP/OTP 跳了 → 重新设保护值后再开

## 5. 接鸭子前 (M3 整机到货后) 的 3 步测试

**前提**: UDP6730 验机通过, 万用表 OK, 工具集到位 (烙铁 + 冷压钳 + 剥线钳), 12 AWG 硅胶线 + T 插母 + VE6-12 端子 都到货。电源端按 [wiring-howto.html](udp6730-wiring-howto.html) 方案 A (镀锡裸线) 或方案 C (压接 VE6-12 针型端子) 处理。

```
1. 空载测电源: 万用表 V⎓ 档, 测红黑香蕉孔, 应显示 +12.00 V ✅
2. 空载测整条转接链: 转接线电源端按 wiring-howto.html 处理后接入 UDP6730 端子 (拧紧螺帽),
   T 插母端用万用表测, 红表笔扎 T 插母圆孔, 黑表笔扎长方孔, 应显示 +12.00 V ✅
3. 测鸭子 T 插极性: 鸭子未通电状态下,
   万用表蜂鸣档, 红表笔扎鸭子 T 插公头宽脚,
   黑表笔扎鸭子内部红线裸露端,
   响蜂鸣 = 红线接宽脚 = 标准正接 ✅
   不响 = 反接, 转接头要找卖家做反接版 ❌
```

**3 步全过 → 才能正式给鸭子通电** (先 M1 12V/8A, 不要直接上 M3 25A)。

## 6. 远端补偿 (≤0.9V, 鸭子调试很少用)

后面板有 4 端子: `S+ / S- / 输出+ / 输出-`, 出厂用短接片连。

**何时需要**: 输出线太长 (>1m), 线压降影响舵机供电 → 取掉短接片, 把 S+ 接到负载正极, S- 接到负载负极, 电源自动补偿到负载端实际为 12V。

⚠️ **死硬约束**: 补偿电压 ≤ **0.9V**, 即线压降不超过 0.9V。鸭子的 1m 12AWG 硅胶线 + T 插, 8A 电流压降约 50mV, 远低于 0.9V, **正常用不到远端补偿**。M3 25A 时压降约 0.15V 也 OK。

如果线压降超过 0.9V → 该换更粗的线, 不是开远端补偿能解决的。

## 7. List 模式 / Delayer 模式 (鸭子 walk policy 暂时不用)

- **List 列表**: 48 组 (V/A/时间), 自动按时间序列输出不同 V/A, 用于自动化测试 (老化测试)
- **Delayer 延时器**: 48 组 (开/关/时间), 自动开关 OUTPUT, 用于设备开关电脉冲测试
- 两个**二选一**, 不能同时
- 鸭子项目用途: **暂无**, 后期想模拟"开机冲击"才用得到

进入: 主界面 → ← 或 → 切到 List/Delayer/主界面三态。

## 8. RS-232 SCPI 远程控制 (M4 真机部署后会用到)

**硬件**: 后面板 RS-232 (DB9 母口), 默认 9600/8/N/1。

**上位机软件**: 优利德官网下载 (UDP6730 软件下载页), 装在 Windows PC 上, USB-串口线连接 (TX/RX/GND 三线)。

**官方上位机界面提供**:
- 数据采集 (V/A/W 实时曲线)
- 远程 ON/OFF
- 列表数据导入/导出
- OVP/OCP 远程设置
- 6 个 Quick Settings 快速预设

**鸭子项目用法 (后期)**:
- M4 真机调试时, Pi 3B+ 通过 USB-串口适配器接 UDP6730 RS-232
- SCPI 脚本动态调电流限值: 静止时 8A → 走路前自动切 25A → 摔倒时立即 0A
- 等价于"软件版 M1/M2/M3 切换", 不用手动按面板

**SCPI 协议细节**: 说明书未详列, 需从优利德官网下载完整 SCPI Manual (型号 UDP67xx 通用)。

## 9. 故障速查表

| 症状 | 排查 |
|---|---|
| 电源无输出 (按 OUTPUT 灯没亮) | 1. V/A 设定不是 0; 2. 没在 OVP/OCP/OTP 触发态; 3. 远端补偿线压降没超 0.9V |
| OUTPUT 灯亮但屏幕显示 0V | 输出端有短路, 或 OCP 触发立即跳 → 关 OUTPUT, 测负载电阻 |
| 屏幕显示 CC (恒流模式) | 负载电阻太小, 电流到达限值, 电压自动降低 → 这是正常保护, 想升压就要增大限流 |
| OTP (过温) 跳 | 长时间满载, 风扇散热不够 → 关一阵让风扇降温, 同时检查通风 |
| 键盘按不动 | LOCK 灯亮 → 短按 LOCK 解锁 |
| 蜂鸣狂响 | OVP 或 OCP 触发了, 看屏幕 OVP/OCP 旁边的 √ 标识和当前 V/A 数值 |
| 输出电压 ≠ 显示电压 (差 > 100mV) | 检查转接线压降, 万用表换档 (200mV 档), 必要时开远端补偿 |

## 10. 设备保养红线

- 操作温度 **0-40°C**, 湿度 20-80% 非冷凝
- 海拔 ≤2000m
- 测量精度: 温机 **半小时**后开始用 (手册原文)
- 清洁: 干净布蘸**少许清水**擦, **不能用酒精/汽油**, 不可水进机内
- 替换保险丝: 移除电源线 → 打开 AC 插座下方保险丝卡槽 → 取出旧丝 → 装回 (出厂随机配 2 个备用 250V/5A)
- **不可拆机**, 内部电路私自改动会丧失保修
