**接线方式 (新)**:
```
UDP6730 红/黑端子 (4mm 香蕉孔 + 接线柱二合一)
  ↓ 拧松彩色螺帽 → 横孔露出
[镀锡裸线 (方案 A)] 或 [VE6-12 针型端子 (方案 C)]
  ↓ 拧紧螺帽 (轴向压紧, 不靠香蕉头摩擦)
[12AWG 硅胶线 1m]
  ↓
[T 插母头] (镀锡焊接到 12 AWG 末端)
  ↓
鸭子 T 插公头 (鸭子端)
```

工具需求: 烙铁 + 焊锡 (方案 A) 或 冷压钳 + VE6-12 端子 (方案 C), 加自动剥线钳. 详见 [`wiring-toolset-shopping-list.md`](wiring-toolset-shopping-list.md).

## 4. 收货后必做的 3 步测试 (UDP6730 + 万用表 + 转接线到货)

详见 [当前的转接链确认对话], 简版:

1. **空载测电源**: 万用表 V⎓ 档, 红表笔扎电源红色香蕉孔, 黑表笔扎黑色, 应显示 **+12.00 V**
2. **空载测整条转接链**: 转接线电源端按 [`udp6730-wiring-howto.html`](udp6730-wiring-howto.html) 方案 A/C 接入 UDP6730 (拧紧螺帽), T 插母端用万用表测, 应显示 **+12.00 V** (T 插母圆孔扎红, 长方孔扎黑)
3. **测鸭子 T 插极性**: 万用表蜂鸣档, 红表笔扎鸭子 T 插公头**宽脚**, 黑表笔扎鸭子内部红线裸露端, **响蜂鸣 = 红线接宽脚 = 标准正接** ✅; 不响 = 反接, 转接头要找卖家做反接版
