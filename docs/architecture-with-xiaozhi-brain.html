⬆️ 上行数据流: 用户说话 → 小智听懂

  1. 用户对鸭子说话 → 🎤 麦克风 拾音
  2. USB 音频 → py-xiaozhi 拿到 PCM 流
  3. Opus 编码 → WiFi → 云端 WebSocket 网关
  4. 音频 → ASR 转成文字 ("你好呱呱~")
  5. 文字 + 性格 prompt + MCP 工具集 → 喂给 LLM 大脑

⬇️ 下行数据流: 小智说话 + 鸭子动作

  1. LLM 输出回复文字 + 决策要不要调工具
  2. 回复文字 → TTS 合成音频 → 经 WebSocket 推回设备 → Speaker 播放
  3. (若调工具) MCP JSON → WebSocket → py-xiaozhi → guagua MCP Tools
  4. Skill Layer 翻译 (例: walk_to → 7 维 command)
  5. ONNX 50Hz 推理 → 14 关节角 → ST3215 舵机 执行 (走/转/挥手)
  6. 同时 Skill 调表情 YAML → 2× SG90 头眼表情
