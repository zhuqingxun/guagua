# 接线/焊接工具购物清单

> 用途: 给鸭子项目接 UDP6730 电源 (12 AWG 主电源裸线接入) + 后续 ST3215 / GPIO / I2C / RS232 焊接和压接.
> 决策辅助文档, **完成采购后请在 [hardware-inventory.md](hardware-inventory.md) 登记实际购入项**, 本文不维护"已购/未购"状态.

**最后更新**: 2026-05-19
**关联**: [udp6730-wiring-howto.html](udp6730-wiring-howto.html) (接线 SVG 图解 + 方案 A/C 穿线技巧), [udp6730-quickstart-cheatsheet.md](udp6730-quickstart-cheatsheet.md) (UDP6730 开机 cheatsheet)

> **2026-05-19 实测修正**: 用户实测剥皮后的 12 AWG 多股硅胶线**无法**直接插入 UDP6730 横孔——绞合后裸铜实际外径约 3.0-3.5 mm,**横孔实际孔径疑似 < 3 mm**(手册未给出规格)。原方案 A (镀锡直接塞) **可能仍不成立**(镀锡后直径变化不大甚至略增)。**主推改为方案 C (VE6-12 针型冷压端子,针标准直径 ~2.5 mm)**,本清单已加入游标卡尺用于实测横孔验证。

## 避坑清单 (照单不买)

- ❌ **4 平方"灯笼头"** - 内部夹片按 4mm² 径向夹紧, 12 AWG 偏细夹不住 (已确认踩坑)
- ❌ **4mm 航模子弹头** - 实心圆柱无弹性分叉, 25A 摩擦接触不可靠 + 需要焊接尾巴 + 电源端没有匹配母头
- ❌ **不温控烙铁** (创耐 / Yihua 60W 直插套装) - 温度跑偏易烧 ST3215
- ❌ **三合一多用钳** (剥+压+剪) - 哪样都不专业, 硅胶皮剥不好, 压接也不到位
- ❌ **非棘轮冷压钳** (螺丝刀/剪刀式) - 压力不均, VE6-12 大端子压不到位
- ❌ **4mm 香蕉头** - UDP6730 端子是接线柱二合一, 直接接裸线即可, 不需要香蕉头

## 采购后第一件做的事

1. **先用游标卡尺量 UDP6730 横孔实际孔径**(拧松螺帽,把卡尺细头伸进去),记录到本文档底部备查
2. 烙铁加热到 350℃, 焊锡丝挂一小段试验 → 锡光滑流动 = OK
3. **空载试塞 VE6-12 端子的针部分(不接线)**: 能进 = 走方案 C, 进不去 = 量针实际直径再决定
4. 12 AWG 硅胶线剥皮 (剥线钳) → 按图解方案 C 压 VE6-12 端子 (方案 A 镀锡仅在横孔实测 ≥3.5 mm 时考虑)
5. 拧松 UDP6730 红/黑端子彩色螺帽 → 穿入 VE6-12 针端 → 拧紧
6. 另一端焊接或压接 T 插母头
7. 万用表 V⎓ 档测红黑端子, 验机 (按 cheatsheet §4 流程)
8. **完成后在 [hardware-inventory.md](hardware-inventory.md) 添加一行**: `工具集 ¥XXX 已购 (清单见 wiring-toolset-shopping-list.md)`
